# S.E.S.M (befintlig sida, exporterad)

Det här är den befintliga sidan, uppdelad i filer utan designändringar.

- index.html        sidans HTML (allt innehåll)
- src/styles/main.css  all CSS
- src/main.js       all JavaScript
- public/logo.png   logotypen (den finns också inbäddad i index.html)

Kör så här i Visual Studio Code:

    npm install
    npm run dev

Viktigt: den här sidan använder Claude-miljöns inbyggda funktioner för
databas, inloggning och AI. Utanför Claude finns de inte, så de delarna
visar sina "inte tillgänglig"-meddelanden. Sparning i webbläsaren fungerar
fortfarande där sidan använder den.
